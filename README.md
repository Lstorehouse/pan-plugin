# 生化盘客户管理插件

Win7+ 单机桌面程序：读取每月**补盘名单（xlsx）**与**退款名单（txt）**，按客户搜索查询补盘与抵扣情况，本地记账。源数据文件只读（ADR-0001）。

## 使用方法

1. 双击打开 `PanPlugin.exe`（Win7 需先安装 [.NET Framework 4.8 运行时](https://dotnet.microsoft.com/download/dotnet-framework/net48)，Win10/11 已内置）。
2. 顶部 **导入补盘名单…** 选 xlsx（自动识别明细底表，VS2 综合盘自动跳过）。
3. **导入退款名单…** 选 txt（"xx客户 5张78元，3张68元"格式自动解析，档位折算抵扣：78→10 元/张、68→20 元/张、30→8 元/张）。
4. 每次导入会弹出**账期确认**：显示从文件名识别出的月份（如 `2026-10`），请核对后再点"确认导入"；改月份可手工输入，取消则不写入任何数据。账期相同才判定重复导入，因此换月导入不会漏账、误选上月文件也能拦住（见 [ADR-0003](./docs/adr/0003-import-period-in-dedup.md)）。
5. 搜不到客户时按提示**关联到已有客户**（名字存为别名，下次自动识别）或**新建客户**。
6. 客户详情：待补盘按盘型分列张数；补发后勾选 → "标记已补发"；抵扣可手工增减、可撤销。抵扣余额与待补盘是**跨月累计**值，不按月清零。
7. 本地数据在 `%APPDATA%\PanPlugin\store.json`（客户主库 + 调整账本）。

## 数据备份

- 每次关闭软件会询问**是否备份**；备份失败时可选择不关闭，避免没备份就退出。
- 顶部 **立即备份…** 可随时手动备份（无需关闭软件）。
- 备份位置：程序目录下的 `Backups\`（用户可直接拷走）；若程序装在只读位置，自动回退到 `%APPDATA%\PanPlugin\Backups\`。弹窗里会显示实际路径。
- 文件名 `store-yyyyMMdd-HHmmss-fff.json`，**最多保留 3 份**，超出自动删除最早的备份。
- 备份前会先保存一次账本，因此包含本次打开期间的全部改动。

## 客户归档／恢复

补盘完成的客户可以**归档**（不是删除）：选中客户 → **归档所选客户…**；若还有未补盘或未用完的抵扣余额会先警告确认。

- 归档客户默认不出现在列表和搜索里；勾选 **显示已归档** 可查看（带"（已归档）"标记），再点 **恢复该客户** 即可手动恢复。
- 档案、别名、全部历史账目完整保留，不做物理删除（见 [ADR-0004](./docs/adr/0004-archive-instead-of-delete.md)）。
- **下月又有补盘会自动重新出现**：导入补盘名单时，只要按主名/别名命中该归档客户并真正入账了新的补盘条目，就会自动解除归档，状态栏提示"↻ N 个归档客户因新补盘已自动恢复显示"。手工新增补盘同样会触发；仅退款/抵扣入账不会。

## 别名纠错

选中客户后点 **管理别名…**（客户名右侧），可以改主名、删除误绑的别名、新增别名，或把某个别名**转移给另一个客户**。改主名时旧名字会自动保留为别名，历史导入仍能命中。

- 别名是精确匹配：一旦名字被误加为某客户的别名，后续导入同名数据会静默归到该客户，不再弹确认。因此删除别名时，程序会记入"已解除关联"，下次导入时该客户不再出现在模糊候选里，避免再次绑错。
- 所有改动在对话框里暂存，点「确定」才生效，「取消」不留痕迹。
- **注意**：别名管理只纠正"以后归到谁"，不会搬动已经入账的补盘／抵扣记录。若错绑已产生账目，需要额外的「转移账目／合并客户」功能。

## 获取程序

无需本地安装任何开发环境：push 到 GitHub 后，Actions 自动在云端编译，到仓库 **Actions → build → Artifacts** 下载 `PanPlugin-win7`（解压后运行 `PanPlugin.exe`）。
