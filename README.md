# 生化盘客户管理插件

Win7+ 单机桌面程序：读取每月**补盘名单（xlsx）**与**退款名单（txt）**，按客户搜索查询补盘与抵扣情况，本地记账。源数据文件只读（ADR-0001）。

## 使用方法

1. 双击打开 `PanPlugin.exe`（Win7 需先安装 [.NET Framework 4.8 运行时](https://dotnet.microsoft.com/download/dotnet-framework/net48)，Win10/11 已内置）。
2. 顶部 **导入补盘名单…** 选 xlsx（自动识别明细底表，VS2 综合盘自动跳过）。
3. **导入退款名单…** 选 txt（"xx客户 5张78元，3张68元"格式自动解析，档位折算抵扣：78→10 元/张、68→20 元/张、30→8 元/张）。
4. 每次导入会弹出**账期确认**：显示从文件名识别出的月份（如 `2026-10`），请核对后再点"确认导入"；改月份可手工输入，取消则不写入任何数据。账期相同才判定重复导入，因此换月导入不会漏账、误选上月文件也能拦住（见 [ADR-0003](./docs/adr/0003-import-period-in-dedup.md)）。
5. 搜不到客户时按提示**关联到已有客户**（名字存为别名，下次自动识别）或**新建客户**。
6. 客户详情顶部是两张**指标卡**（待补张数 / 抵扣余额）；下方「待补清单」按盘型列出工单，补发后勾选 → **勾选项标记已补发**；「历史账目」可撤销、转移记录、手工增减抵扣。抵扣余额与待补盘是**跨月累计**值，不按月清零。
7. 本地数据在 `%APPDATA%\PanPlugin\store.json`（客户主库 + 调整账本）。

## 界面导览（ADR-0008 / ADR-0009）

- **顶部**：搜索框（`Ctrl+F` 聚焦，空框有「输入客户名或别名…」提示）、1 个主按钮「导入补盘名单…」、1 个次按钮「导入退款名单…」、文字按钮「立即备份…／恢复备份…」和 **更多…**（归档/恢复、合并到另一客户、转移记录）。鼠标悬停按钮会显示完整说明。
- **左栏**：筛选胶囊「全部 / 待补 / 有余额」显示实时数量，可勾选「待补优先」把要处理的客户排到前面；客户行右侧是**固定槽位的语义徽标**（待补红 / 抵扣绿 / 已归档灰），长名字自动省略号，不会把徽标挤走。「显示已归档」也在这一栏。
- **右栏**：客户名 + 管理别名 → 两张指标卡 → 「待补清单 N」表格 + 紧贴表格的操作条 → 「历史账目 N」表格 + 紧贴表格的操作条。表格去掉了重网格，**列宽按权重铺满窗口**（Resize 自动重算），「工单号 / 状态 / 账期 / 来源」各自成列；被省略号截断的工单号/来源可把鼠标停在该行查看完整信息。某张表没有记录时会**自动收起高度**，把空间让给另一张表。
- **状态栏**：左侧常驻 `账期 · 客户数 · 待补家数 · 最近备份时间`，右侧是快捷键提示与本次操作的临时提示。`Ctrl+F` 聚焦搜索、`F5` 刷新。
- 所有对话框外观统一（主按钮填充、次按钮描边），按钮宽度按文字实测自动决定，中文文案不会被裁掉。

## 高 DPI 显示（ADR-0009）

程序通过 `app.manifest` 声明**系统级 DPI 感知**，并配合 `AutoScaleMode.Dpi` 把控件几何按 DPI 等比放大。在 200% 缩放下窗口与文字都由程序按真实 192 DPI 绘制，**字体清晰**（不再由 Windows 把 96 DPI 位图放大 2 倍），界面物理尺寸与之前保持一致。

- Win7 只需 .NET Framework 4.8 即可，不依赖任何新 API。
- 采用系统级感知，不处理运行时 DPI 变化：把窗口拖到不同缩放比例的显示器上，需重启程序才会按新 DPI 重绘。
- 建议在 100% / 125% / 150% / 200% 四档缩放下各打开一次，重点看按钮文字、对话框布局与两张表的列宽。若某个缩放档出现错位，请回传截图。

## 数据备份

- 每次关闭软件会询问**是否备份**；备份失败时可选择不关闭，避免没备份就退出。
- 顶部 **立即备份…** 可随时手动备份（无需关闭软件）。
- 备份位置：程序目录下的 `Backups\`（用户可直接拷走）；若程序装在只读位置，自动回退到 `%APPDATA%\PanPlugin\Backups\`。弹窗里会显示实际路径。
- 文件名 `store-yyyyMMdd-HHmmss-fff.json`，**最多保留 3 份**，超出自动删除最早的备份。
- 备份前会先保存一次账本，因此包含本次打开期间的全部改动。
- 顶部 **恢复备份…** 列出所有备份（最新在前，显示时间、大小、客户数/账目数），选中后二次确认即可恢复。恢复前会把**当前账本另存为** `before-restore-*.json`，不会被 3 份轮转删掉（这类文件也只留最近 3 份）。
- 恢复会整体覆盖当前数据并重新载入账本；合并客户等不可逆操作前程序也会自动生成备份，可用这里还原。

## 客户归档／恢复

补盘完成的客户可以**归档**（不是删除）：选中客户 → 顶部 **更多… → 归档所选客户…**；若还有未补盘或未用完的抵扣余额会先警告确认。

- 归档客户默认不出现在列表和搜索里；勾选 **显示已归档** 可查看（带灰色「已归档」徽标），再点 **更多… → 恢复该客户** 即可手动恢复。
- 档案、别名、全部历史账目完整保留，不做物理删除（见 [ADR-0004](./docs/adr/0004-archive-instead-of-delete.md)）。
- **下月又有补盘会自动重新出现**：导入补盘名单时，只要按主名/别名命中该归档客户并真正入账了新的补盘条目，就会自动解除归档，状态栏提示"↻ N 个归档客户因新补盘已自动恢复显示"。手工新增补盘同样会触发；仅退款/抵扣入账不会。

## 别名纠错

选中客户后点 **管理别名…**（客户名右侧），可以改主名、**重命名别名**、删除误绑的别名、新增别名，或把某个别名**转移给另一个客户**。改主名或改别名时，旧名字会自动记为"已解除关联"，历史导入不会再静默绑回本客户。改别名：在列表里选中 → 在"改名为"输入框改字 → 点 **应用改名** → 最后点「确定」生效。

- 别名是精确匹配：一旦名字被误加为某客户的别名，后续导入同名数据会静默归到该客户，不再弹确认。因此删除/改名时，程序会记入"已解除关联"，下次导入时该客户不再出现在模糊候选里，避免再次绑错。
- 所有改动在对话框里暂存，点「确定」才生效，「取消」不留痕迹。

## 合并客户

有时一个名字被**新建成了独立客户**（例如"黄强"其实是"鹤壁市安志宠物医院"的联系人），它会在列表里单独占一行，改别名解决不了。这时选中该客户 → **合并到另一客户…** → 搜索并选择目标客户 → 二次确认：

- 源客户名及其全部别名变成目标客户的别名；
- 源客户名下所有账目转到目标客户（生成转移日志，可在「转移记录…」查看）；
- 源客户档案被移除，列表里不再有重复行。

入口在顶部 **更多… → 合并到另一客户…**。合并**不可逆**，因此执行前会自动生成一份备份；如需还原请用「恢复备份…」（见 [ADR-0007](./docs/adr/0007-merge-and-restore.md)）。

## 转移账目（纠错）

错误归属已经产生账目时：在客户详情的**历史列表里勾选**要搬走的记录 → **所选记录转移到…** → 搜索并选择目标客户 → 二次确认。程序**逐条**改写记录的客户归属，待补盘与抵扣余额会跟着变化。

- 每次转移生成一条**转移日志**；点 **更多… → 转移记录…** 可查看时间、源客户 → 目标客户、条数，选中后点「撤销所选转移」即可**整批撤销**回原客户。
- 撤销时自动跳过已删除、已不在目标客户名下、或被更晚的转移批次重新处理过的记录，不会覆盖后续操作；结果会提示实际撤销条数与跳过条数。
- 待补清单与历史列表都带勾选框（"勾选项标记已补发"依赖它，已补发的条目显示为已勾选状态）。

## 获取程序

无需本地安装任何开发环境：push 到 GitHub 后，Actions 自动在云端编译，到仓库 **Actions → build → Artifacts** 下载 `PanPlugin-win7`（解压后运行 `PanPlugin.exe`）。

- 技术：C# + WinForms，目标框架 net48（ADR-0002）；`src/PanPlugin/app.manifest` 负责 DPI 感知（ADR-0009）
