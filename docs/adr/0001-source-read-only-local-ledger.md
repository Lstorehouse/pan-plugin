# 源数据文件只读，增减记入插件本地调整账本

数据源是每月更新的 Excel 业务文件，直接改写有文件占用、格式损坏、破坏历史数据三重风险。因此决定：插件对源数据文件**只读**，补盘/退款盘的增减全部记入插件自己的本地调整账本，界面展示"源数据 + 本地增减"的合并视图。

**Considered Options**:
- 直接写回源 Excel —— 否决：文件可能正被 Excel 打开、格式易损、无法撤销。
- 导出变更记录交给别人落实 —— 否决：链路断裂，实时性差。

**Consequences**: 源文件与账本可能出现口径不一致（如线下手工补了盘但没记账），需要提供对账/手动校正手段。
